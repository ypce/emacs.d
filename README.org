#+title: Emacs Config
#+author: Vytautas

Personal Emacs config. The directory is the repo, so clone it into
place:

#+begin_src sh
git clone git@github.com:ypce/emacs.d.git ~/.emacs.d
#+end_src

Runtime state (=elpa/=, =eln-cache/=, history files) stays out of git.

* Install (macOS)

Emacs 30+ as a login daemon:

#+begin_src sh
brew tap d12frosted/emacs-plus
brew install emacs-plus@30
brew services start emacs-plus@30
#+end_src

Shell aliases. =-a ''= starts a daemon when the service is down, so
these always connect:

#+begin_src sh
alias e="emacsclient -nw -a ''"     # terminal frame
alias ec="emacsclient -r -n -a ''"  # GUI frame
#+end_src

External tools, all optional. A missing tool only disables its own
feature:

#+begin_src sh
brew install coreutils pandoc ripgrep fd
brew install gopls marksman bash-language-server python-lsp-server
brew install --cask font-symbols-only-nerd-font   # GUI glyph icons
#+end_src

GUI frames use *Aeonik Mono Medium 18* - install the =.otf= family
into =~/Library/Fonts=, or live with the default mono.

For Finder, set *Emacs Client.app* (an emacsclient droplet) as the
handler for text files. Opening Emacs.app directly starts a second
instance that ignores the daemon.

The first start downloads the packages into =elpa/= and builds the
tree-sitter grammars (needs git and a C compiler). Native-comp
warnings in the first sessions are normal.

* Terminal colors

The daemon has no =COLORTERM=, so tty frames only get 24-bit color
from terminfo. Install an entry per terminal:

#+begin_src sh
# ghostty (also fixes "Terminal type xterm-ghostty is not defined")
TERMINFO=/Applications/Ghostty.app/Contents/Resources/terminfo \
  /opt/homebrew/opt/ncurses/bin/infocmp -x xterm-ghostty > /tmp/ghostty.ti
/opt/homebrew/opt/ncurses/bin/tic -x -o ~/.terminfo /tmp/ghostty.ti

# wezterm (also set `term = "wezterm"` in wezterm.lua)
curl -s https://raw.githubusercontent.com/wezterm/wezterm/main/termwiz/data/wezterm.terminfo -o /tmp/wezterm.ti
/opt/homebrew/opt/ncurses/bin/tic -x -o ~/.terminfo /tmp/wezterm.ti
#+end_src

=M-: (display-color-cells)= in a client frame must say =16777216=.

* App icon (optional)

A brew rebuild restores the stock icon; reapply *elrumo2* after:

#+begin_src sh
curl -sL -o /tmp/e.icns https://raw.githubusercontent.com/d12frosted/homebrew-emacs-plus/master/community/icons/elrumo2/icon.icns
for f in "/Applications/Emacs.app/Contents/Resources/Emacs.icns" \
         "/opt/homebrew/opt/emacs-plus@30/Emacs.app/Contents/Resources/Emacs.icns" \
         "/Applications/Emacs Client.app/Contents/Resources/applet.icns"; do
  /bin/cp /tmp/e.icns "$f"
done
touch /Applications/Emacs*.app && killall Dock
#+end_src

* Using it

Modal editing is *meow* with the Colemak layout, selection first.
=SPC= opens the leader menu (which-key shows the labels), =SPC ?=
shows the meow cheatsheet. Everything else is stock Emacs chords.
Minibuffer completion is vertico + orderless + marginalia; consult
and embark/wgrep drive live search (=SPC /=, =SPC n /=) and bulk
find/replace across results. In-buffer completion is the built-in
completion-preview.

Notes live in =~/Notes= (org-node). The agenda reads =inbox.org=,
=agenda.org=, and any file tagged =#+filetags: :agenda:=.

No lockfiles; versions float. =M-x package-upgrade-all= updates
everything.
